# AI Learning Roadmap Generator for Career Skills

A capstone project that compares AI-generated learning plans and builds a practical 12-week roadmap for a beginner preparing for data analyst work.

> **Project status:** The core roadmap and supporting documents are assembled. Some rubric evidence is still pending, including proof of four free-tier AI tools, mapping six AI skills to the course topics, a successfully run email reminder automation, a complete before/after evaluation, and the final demo. See [Submission Criteria and Readiness](Submission%20Criteria%20and%20Readiness.docx) for the detailed cross-check.

## Project overview

The project examines three AI-generated roadmaps, compares their sequencing and learning activities, checks the suggested learning resources, and combines useful elements into a revised plan. The roadmap targets a complete beginner, suggests 5–7 hours of study per week, and culminates in a documented data analysis portfolio project.

The revised plan emphasizes practical evidence: spreadsheet summaries, SQL queries, Python/Pandas notebooks, data cleaning notes, visualizations, a dashboard, and a final presentation. It is a learning plan, not a guarantee of employment or job readiness within a fixed period.

## Project objectives

- Generate alternative roadmaps for a beginner learning data analysis.
- Compare topic coverage, sequence, workload, practice tasks, resource quality, and portfolio guidance.
- Check resource claims against provider information and record uncertainty.
- Produce a clearer roadmap with measurable weekly outputs.
- Provide a tracker, infographic, reusable prompts, and evidence checklist to support the work.

## Roadmap at a glance

1. **Weeks 1–2:** Spreadsheet foundations, cleaning, formulas, pivot tables, and data questions.
2. **Weeks 3–5:** SQL querying, aggregation, joins, subqueries, CTEs, and exporting results.
3. **Weeks 6–7:** Python and Pandas, followed by data cleaning and exploratory analysis.
4. **Week 8:** Descriptive statistics and careful interpretation.
5. **Weeks 9–10:** Visualization, dashboard building, and validation.
6. **Weeks 11–12:** Portfolio assembly, documentation, review, and presentation.

The revised roadmap includes weekly tasks, resources, time estimates, and completion evidence. It recommends choosing a suitable public dataset early and reusing it across the project. Dataset licensing and privacy should be checked before publishing.

## Resource and access notes

Resource plans and features can change. The project records these important limitations:

- Kaggle Learn course pages describe their courses as no-cost; account and usage conditions can still apply.
- SQLBolt provides interactive SQL lessons, but the supplied lesson list does not establish that it teaches CTEs or window functions. The revised roadmap points to Kaggle Intro to SQL for CTE exposure and treats window functions as optional extension work.
- Tableau Public is intended for public sharing. Do not upload confidential or restricted data.
- Microsoft Learn training can be accessed independently of report-sharing entitlements. Power BI free users can create reports for personal use, while sharing or publishing to shared workspaces may require a paid license or qualifying capacity.
- Certificates and paid subscriptions are optional and are not required by the revised roadmap.

Check official provider pages immediately before submission and note the date checked in the verification record.

## Responsible use and limitations

AI-generated roadmaps can contain inaccurate links, access claims, or unrealistic assumptions. This project treats AI output as a draft that requires independent checking. Resource availability, free-tier limits, software access, and dataset licenses may vary by account and date. Completing this roadmap does not guarantee a job, certification, or a specific level of proficiency.
